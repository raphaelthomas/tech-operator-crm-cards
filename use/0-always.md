# ⚓ Always

| | |
| :--- | :--- |
| **Fit for duty?** | **IMSAFE** — **I**llness · **M**edication · **S**tress · **A**lcohol · **F**atigue · **E**motion. Any red: hand off. |
| **Every instruction** | Three-way: sender states → receiver repeats → sender confirms. |
| **While executing** | Sterile cockpit — essential comms only. |
| **Something looks wrong** | **PACE** — **P**robe · **A**lert · **C**hallenge · **E**mergency. Two unanswered challenges: go over their head. |
| **Major incident** | Name roles aloud: **Commander** (plan) · **Comms** (external) · **Ops** (keys). Never one person for all three. |
| **Throughout** | Write it down as it happens. |
