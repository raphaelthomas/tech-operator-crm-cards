# 🚨 During an Incident

## Reset — 10 for 10

Ten seconds now buys ten minutes. Aloud: **problem? · facts? · plan? · roles? · questions?**
Run it again whenever the picture changes.

## Scope — Is / Is-Not

| | Is | Is not |
| :--- | :--- | :--- |
| **What** is failing | | |
| **When** it started | | |
| **Where** it happens | | |

The boundary is the clue.

## Decide — FOR-DEC

**F**acts · **O**ptions · **R**isks · **D**ecision · **E**xecution · **C**heck

Two options minimum, including doing nothing. Check it, or it did not happen.

## Stop rules

| | |
| :--- | :--- |
| **Fixated** | Stand up. Sixty seconds. Then come back. |
| **Past your time-box** | Escalate — do not extend. Escalation is not a sin. |
| **Break** | Every couple of hours. Risk roughly doubles across one continuous stretch. |
| **Hand off** | By 8–10 hours on it. Past 17 hours awake you are impaired like 0.05% blood alcohol. |
| **Customer waiting** | Give a next-update time, then hit it. |

### Solo
- No Monitor: read the command aloud to yourself before you commit it.
- No one to challenge you: ask the pre-mortem question out loud anyway.
