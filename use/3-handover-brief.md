# 🤝 Handover Brief

## SBAR

| | |
| :--- | :--- |
| **S**ituation | What is happening now, and the impact |
| **B**ackground | What changed, and what you already tried |
| **A**ssessment | What you think it is, and how bad |
| **R**ecommendation | Exactly what you need from them |

## Check-back

They repeat the brief back. You confirm.

## Transfer control

Three exchanges, out loud, in this order:

> — **"You have control."**
> — **"I have control."**
> — **"You have control."**

**It is not handed over until all three have been said.**
